Its three native packs, versions, manifest/query bytes, 44 source inputs, reference
identities and profiles remain fixed. JavaScript's seven historical native inputs
remain unsupported. JSX has no native pack. Global capability changes cannot add
packs, strict comparison cells or applicable baselines to this experiment.

The native report keeps its original path, union/failure rules and denominators.
Changed experiment inputs fail explicitly. Actual component, runtime and source
build fingerprints still come from the existing generator. A genuine build-input
change may require regenerating those identities; it does not authorize changing
scores, corpus membership or reference truth. Both historical report paths use
the original baseline applicability.

JSON, TypeScript and TSX retain `json`, `typescript`, `ts`, `cts`, `mts` and `tsx`.
JavaScript, `js`, JSX and `node` stay outer-only even if root capability grows.
Nested/list, unknown, empty and Markdown fence behavior is unchanged.

tree-sitter-javascript 0.25.0 parser and JavaScript highlights followed by JSX
highlights. It obtains `source.js.jsx` from the actual JSX registration. Assets,
hashes, notices and acquisition roles are unchanged. JavaScript diagnostics keep
their existing query order and output. VS Code TypeScript remains N/A for both.
Complete patterns requiring `#is-not? local` remain excluded and recorded.

native predicates nor establishes target scope truth. Native JS/JSX packs and
shared-parser public identity guards remain separate prerequisites.
